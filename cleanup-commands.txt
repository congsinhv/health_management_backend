================================================================================
JENKINS DISK CLEANUP - COPY & PASTE COMMANDS
================================================================================

STEP 1: SSH into your Jenkins server
-------------------------------------
ssh your-user@your-jenkins-server


STEP 2: Run this ONE command (comprehensive cleanup)
-----------------------------------------------------
sudo docker system prune -af --volumes && sudo docker builder prune -af && df -h && docker system df


STEP 3: If you need MORE aggressive cleanup
--------------------------------------------
sudo systemctl stop docker && \
sudo rm -rf /var/lib/docker/overlay2/* && \
sudo rm -rf /var/lib/docker/containers/* && \
sudo rm -rf /var/lib/docker/image/* && \
sudo rm -rf /var/lib/docker/volumes/* && \
sudo systemctl start docker && \
df -h


STEP 4: Verify disk space
--------------------------
df -h
docker system df


STEP 5: Restart Jenkins (if needed)
------------------------------------
sudo systemctl restart jenkins


================================================================================

================================================================================
QUICK CHECK: Is disk full?
================================================================================
ssh your-user@your-jenkins-server "df -h && echo '---' && docker system df"

================================================================================

- These commands are SAFE - they only remove unused Docker resources
